# Desktop: 資格情報の失効 (盗難・紛失のとき)

ADR-0007 によりディスクは暗号化しない。Desktop のディスク (または筐体) を持ち出されたときは、ここにあるものがすべて読まれる前提で、上から順に失効・交換する。被害の大きい順に並べている。

| 順 | 資格情報 | 失効のしかた | 交換のしかた |
|---|---|---|---|
| 1 | Tailscale のノード鍵 | Tailscale の管理画面で Desktop のマシンを削除する | 再インストールの後、新しい認証鍵でつなぐ |
| 2 | age の秘密鍵 (dotfiles の秘密情報を復号する鍵) | 秘密鍵そのものは失効できない。暗号文は公開リポジトリにあるので、**中身をすべて交換する**前提で動く | 新しい鍵を作り、受け手を差し替え、すべての `*.age` を再暗号化する。そのうえで中身の秘密を下の各行に従って交換する |
| 3 | 推論 API の鍵 | Server 側の設定から古い鍵を外す (Server への連絡が要る) | 新しい鍵を作り、age で暗号化して置く |
| 4 | SSH 鍵 | GitHub と Server の `authorized_keys` から公開鍵を外す | 新しい鍵を作って登録する |
| 5 | GitHub のトークン (gh など) | GitHub の設定でトークンを失効させる | 作り直す |
| 6 | エージェント CLI の API トークン | 各サービスの管理画面で失効させる | 作り直す |
| 7 | ブラウザのセッション | 主要なサービスで「すべての端末からログアウト」を実行する。パスワードマネージャのセッションも切る | — |
| 8 | restic のパスワード | HDD も一緒に持ち出されたなら、バックアップは読まれる前提にする | 新しいリポジトリを作り直す |

## 確認

- 失効を終えたら、台帳 (`ledger.md`) に日付と、失効したものの一覧を残す。
- この表の行は、資格情報を足したときに更新する。機能テスト `doctor/secrets` が、age で管理する秘密情報の一覧とこの表を突き合わせる (段階4)。
