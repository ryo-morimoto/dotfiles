## 1. Broken, no good entry in boot menu

Rule broken: When the desktop is broken, the boot menu always still has an entry that worked.
This is the only way to get here in the model.

0. Start: Desktop works
1. Update breaks the desktop. Now: Broken by update, good entry kept
2. Update again while broken. Now: Updated again while broken, good entry kept
3. Cleanup deletes the old snapshots. Now: Broken, no good entry in boot menu
