# Fedora bootc (Zirconium 派生) / Fedora Atomic + layering / Universal Blue の事実 (取得日 2026-10-24)

## 候補の定義

- **A: Fedora bootc (Zirconium-nvidia 派生)**: `ghcr.io/zirconium-dev/zirconium-nvidia:latest` を `FROM` にした自前イメージを CI (GitHub Actions など) でビルドしてレジストリに置き、ホストは `bootc switch` / `bootc upgrade` / `bootc rollback` で運用する構成。
- **A'-1: Fedora Atomic + rpm-ostree layering**: Fedora Atomic (Silverblue / Sway Atomic などの rpm-ostree 系) に `rpm-ostree install` で niri / DMS / akmod-nvidia などを重ねる構成。
- **A'-2: Universal Blue 系イメージ**: Bluefin / Bazzite / ublue `base`(nvidia 版) をそのまま使う構成か、ublue の image-template で派生させる構成。

前提として 2026-10-24 時点で Fedora 43 と 44 が current、45 が frozen (未リリース) である (Bodhi releases API)。Zirconium は Fedora 44 でビルドしている。

### niri + DMS + NVIDIA にどれが近いか (結論の材料)
- Zirconium-nvidia は niri、DMS、NVIDIA ドライバ (negativo17)、fcitx5 + mozc を最初から含む。ただし NVIDIA 版は Secure Boot に対応していない。
- Bluefin は GNOME、Bazzite は KDE/GNOME のゲーム向けで、niri も DMS も入っていない。ublue の `base`(nvidia 版) はデスクトップを含まない土台で、署名済みの NVIDIA open カーネルモジュールを持つ。
- まとめると、niri + DMS + NVIDIA に最も近いのは Zirconium-nvidia。Secure Boot まで満たすのに近いのは「ublue base-nvidia + niri/DMS を自前で追加」。
